🎙️ DramaFlow 声音路由与角色音色编排流程
=====================================================

📥 输入：结构化剧本 (Script JSON)
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 1. 语种探测与旁白强绑定 (synthesizer.py & audio_engine.py)│
│    检测全剧文本字符集:                                 │
│    ✓ 含有中文字符？                                    │
│      → YES: 中文剧本，旁白锁定 zh-CN-YunxiNeural       │
│      → NO:  英文剧本，旁白锁定 en-US-BrianNeural       │
│    (注: 旁白严格剥离段落的 gender 属性，保证全篇音色如一) │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 2. 角色确定性哈希选角 (audio_engine.py / assign_voices) │
│    针对剧本中所有 dialogue 角色:                        │
│    voice_index = MD5(character_name) % len(voice_pool) │
│    ✓ 同一角色在任意章节始终绑定同一个 Voice ID           │
│    ✓ 前端可通过 manual override 自由替换指定的 Voice ID │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 3. 多云 TTS 智能路由决策 (select_provider & generate)  │
│                                                        │
│  ┌─ 若片段为 narration (旁白):                         │
│  │   • VIP 用户  → OpenAI TTS (高保真 Onyx/Alloy)      │
│  │   • Free 用户 → Azure Speech (50万字配额监控)       │
│  │               └─ 触碰上限或故障 → 自动降级至 Google  │
│  │                                                     │
│  └─ 若片段为 dialogue (对白):                          │
│      • VIP 用户  → ElevenLabs (按情绪注入 Stability)   │
│      • Free 用户 → Google Cloud TTS (Neural2/Wavenet)  │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 4. 并发流水线与信号量控制 (synthesizer.py)              │
│    • 旁白部分: 全并发异步生成                          │
│    • ElevenLabs 对白: asyncio.Semaphore(3) 限流防并发封禁 │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 5. 数字音频后期混音与字幕生成 (post_production.py)      │
│    • 变速率微调 pacing                                  │
│    • 段落间拼接 300ms 黄金静音间隙 (silence_gap)       │
│    • 毫秒级时间戳运算，生成 final.srt 与 timeline 索引  │
│    • 混音导出 192kbps MP3 音轨                          │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────┐
│ 6. 云端对象存储分发 (storage.py -> Cloudflare R2)       │
│    • 生成文件先存入 temp/ 目录并返回 Public URL        │
│    • 支持通过 /save_files 转正移入 saved/ 归档目录      │
└────────────────────────────────────────────────────────┘

=====================================================
🎯 核心保障总结:
1. 旁白音色全剧唯一、语种自适应，不受男女角色穿插影响。
2. 角色音色哈希幂等，无需数据库即可实现全剧人物声音一致。
3. 商业化分层流转，VIP 享受电影级音质，免费用户高可用低成本兜底。
4. 所有声音池与参数统一收口在 app/config/voices.json。
